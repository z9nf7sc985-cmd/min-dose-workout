# MinDose — minimum-effective-dose full-body workout (PWA)

A tiny, offline-first workout tracker built around one idea: **hit every muscle with the least work that still drives results.**

- 2-3 full-body sessions/week (~35-45 min), rotating Workout A / B / C
- ~4-10 hard sets per muscle per week, sets taken to 1-3 reps in reserve
- Gym, Dumbbells-only, or Bodyweight/home versions of every exercise, with swaps
- Tap-to-log sets, rest timer, automatic progressive-overload suggestions
- Weekly muscle coverage (body map + bar chart), history, weekly streak
- 100% static; data stays in your browser's localStorage; works offline

**Install on iPhone:** open the site in Safari → Share → *Add to Home Screen*.

Not medical advice. Consult a doctor if you have health conditions; stop on sharp pain.
