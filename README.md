# MinDose — zero-equipment, minimum-effective-dose full-body workouts (PWA)

Hit every muscle with the least work that still drives results — **no tools needed**.

- **Living room** (default): floor + bodyweight, optional couch/chair. Push-up/squat/hip-thrust ladders, sliding leg curls in socks, self-resisted rows & curls, prone Y-T-W, wall lateral presses.
- **Car**: seated self-resisted presses/pulls and isometric holds. **Only while parked with the engine off — never while driving.**
- 2-3 full-body sessions/week rotating A / B / C; ~4-10 hard sets per muscle per week, sets near failure
- Tap-to-log reps/seconds, rest timer, level-up suggestions, weekly muscle coverage (body map + bars), history, streak
- **v3:** animated stick-figure visual for every exercise (`ex/*.svg`, generated by `node tools/build.js`), beginner how-to steps, common mistakes, easier version, difficulty badge, set type, easier→harder ladder, YouTube search link
- "New here? Start here" guide, recommended weekly schedule (Mon/Wed/Fri), 4-week beginner ramp, in-session order + cooldown
- **Meals tab:** cheap (~$5-8/day, rough estimate) car-friendly 7-day plan, grocery list, Sunday batch prep, snacks, goal-based portions, protein calculator; Supplements, Natural & herbal, and a harm-reduction card
- 100% static; data stays in localStorage; works offline

**Install on iPhone:** open the site in Safari → Share → *Add to Home Screen*.

Not medical advice. Consult a doctor if you have health conditions; stop on sharp pain; breathe during isometric holds.
